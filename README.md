# 나의 주간 체크리스트

요일별 업무 · 할 일 · 구매할 일 · 재고 · 메모를 적는 체크리스트입니다. 주소: `/daily-checklist/weekly/`

- 아이폰 · 아이패드: Safari로 열고 공유 버튼 → **홈 화면에 추가**
- 「기기 연동」에서 같은 이메일 계정으로 로그인하면 기기끼리 기록이 맞춰집니다 (Firebase).
- 항목에 시간을 넣으면 시간 순서로 정렬되고, 「기기 연동」 → 「이 기기에서 알림 켜기」를 한 기기에는 그 시각까지 체크하지 않은 항목을 알려 줍니다. 아이폰 · 아이패드는 홈 화면 앱에서 켭니다 (iOS 16.4 이상).

알림 서버는 `push-worker/`(Cloudflare Workers, `https://weekly-push.my-checklist.workers.dev`)입니다. 고친 뒤 그 폴더에서 `npx wrangler deploy`로 올립니다. 알림 서명용 비밀 키(`VAPID_PRIVATE`)는 저장소에 두지 않고 `npx wrangler secret put VAPID_PRIVATE < 키파일.json`처럼 파일에서 바로 넣습니다. 창에 붙여 넣으면 키가 깨질 수 있습니다. 넣은 뒤 서버 주소를 열어 「서명 키 맞음」이 보이는지 확인합니다.

## 나의 매뉴얼 · 회의록

주소: `/daily-checklist/notes/` (홈 화면 이름 「매뉴얼 회의록」)

- **매뉴얼**: 방법(준비할 것 · 단계 · 다 됐는지 확인 · 막힐 때), 점검표(항목), 참고(이름 · 내용, 바로 복사) 세 가지. 보기 화면에서 단계를 눌러 한 일로 표시합니다(이 기기에만).
- **회의록**: 일시 · 장소 · 사회 · 기록 · 참석, 안건마다 논의 · 결정, 할 일(무엇을 · 누가 · 언제까지), 다음 회의. 같은 종류의 회의를 고르면 지난번 장소 · 참석자가 채워집니다.
- **할 일**: 모든 회의록의 끝나지 않은 할 일을 기한 순서로 모아 봅니다.
- 「보내기」는 휴대폰 · 아이패드에서 공유 창(카톡 등), PC에서는 글로 복사입니다. 「더 보기 → 인쇄」로 A4 인쇄 · PDF 저장.
- 연동은 체크리스트와 같은 Firebase 계정입니다. 글 하나가 문서 하나(`users/<uid>/notes/<id>`)이고, 계정 쪽이 이 기기가 마지막으로 맞춘 판일 때만 트랜잭션으로 씁니다. 두 기기에서 같은 글을 고쳤으면 나중 판이 남고 밀린 판은 「(겹친 판 …)」 사본으로 남습니다. 지운 글은 「지운 글」에서 되살릴 수 있습니다.

맨 위 `index.html`은 주간 체크리스트로 보내는 페이지이고, `sw.js`는 예전 일일 체크리스트 앱이 기기에 남긴 저장 화면을 지우는 용도입니다.
