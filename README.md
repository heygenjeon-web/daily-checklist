# 나의 일일 체크리스트

오늘의 세 가지, 시간별 루틴(오전·오후 자동 분류, 요일별 매주 반복), 달력 기록을 담은 설치형 웹앱입니다.

- 아이폰: Safari로 열고 공유 버튼 → **홈 화면에 추가**
- PC: Edge·Chrome 주소창 오른쪽의 **앱 설치** 버튼

기록은 각 기기 안에만 저장되며 서버로 보내지 않습니다. 기기를 옮길 때는 앱 아래의 **백업 파일 내보내기 / 가져오기**를 쓰세요.
